## The problem

Learning tools are often scattered across separate services. Students may need one tool to revisit a lecture, another to clarify a topic, and another to assess their readiness. EduFusion AI explores how these workflows can be brought together in a more coherent educational experience.

## The product

EduFusion AI is an AI-assisted educational platform built around a connected learning workflow.

| Area | What it aims to support |
| --- | --- |
| **Academic risk prediction** | Identify possible learning difficulties earlier and support timely intervention. |
| **LectureScribe** | Turn lecture material into more accessible text-based study resources. |
| **Visual Notes** | Help learners review educational content using visual summaries. |
| **AI learning assistant** | Ask questions and receive context-aware study support. |
| **Practice and assessment** | Support quizzes, lecture study, and oral-exam practice. |

These are product areas with differing implementation and readiness levels, not a claim that every feature is publicly released.

## My involvement

As a **co-founder**, my work spans coordinating product development, contributing to frontend engineering, and integrating AI-assisted workflows into a usable platform. The project has also involved designing how independent learning services fit together in one student experience.

## Engineering themes

- User-centered React interfaces and consistent application workflows
- Backend API integration and service coordination
- Integrating predictive ML and generative AI capabilities
- Authentication, user roles, and careful handling of educational information
- Testing, reliability, and controlled release processes

## What the experience has taught me

Building an AI product is not only about selecting a model. It requires careful system boundaries, reliable integrations, practical user journeys, and honest evaluation of what is ready for real users.
